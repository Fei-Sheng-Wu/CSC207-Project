# CSC207 Project - "Suitable: Personal Outfit Advisor"

[![Java](https://img.shields.io/badge/Java-17-orange.svg?style=flat-square)](#)
[![Build](https://img.shields.io/badge/Build-Maven-green.svg?style=flat-square)](#)

> Suitable is a personalized outfit recommendation program that manages a user’s real-life wardrobe, providing tailored outfit styling suggestions based on weather, occasion, and activities. It eases the everyday process of dressing up by curating new sets of clothes that the user can simply follow, respecting both aesthetic and functionality.

## Get Started

Execute `Main.java` to start the application.

```bash
java Main.java
```
